# Repository guidance

This repository distributes six independent scientific workflow skills in `skills/`. Read the relevant `SKILL.md` and only the references needed for the requested operation.

Keep skills independent of private projects, absolute personal paths and one computer's installed application identifiers. Discover native interfaces on the target installation. Preserve source data and use working copies for native operations.

Keep instructions concise and general. Add rules for demonstrated reusable needs, not every past agent mistake. Maintain scientific identity, provenance and units independently of formatting or script success.

Run `python -B scripts/validate.py` after relevant changes. Native software checks and visual/scientific review remain separate from synthetic tests; document the scope of any claimed validation in `VALIDATION.md`.

Do not add private experimental inputs, credentials, application binaries or copied vendor manuals. Use synthetic fixtures for public tests.
