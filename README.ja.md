# Scientific Workflow Skills

[English](README.md) | [简体中文](README.zh-CN.md) | 日本語

化学・生命科学のワークフローで再利用できる、6 つのエージェント用スキル（skill）です。各スキルには手順と、必要に応じて使うスクリプトや参考資料が含まれます。すべて通常のファイルなので、専用のスキル呼び出し API がなくてもエージェントが直接読み込めます。

**現在は実験版 0.2.3 です。** 実際の研究業務から抽出し、同じコンピューター上で 2 種類のエージェントモデルを使ってテストしました。別のコンピューターでの検証はまだ完了していません。詳しくは[検証状況と既知の制限](VALIDATION.md)（英語）をご覧ください。

## 含まれるスキル

| Skill | 用途 |
| --- | --- |
| [nmr-processing](skills/nmr-processing/SKILL.md) | NMR データの所在を整理し、既存の MestReNova ページをエクスポートします。作業用コピーでのデータ処理や解析の手順も示します。 |
| [prism-ic50-analysis](skills/prism-ic50-analysis/SKILL.md) | 対応する PZFX の XY データを抽出し、Prism の結果のエクスポートを整理して、確認済みの IC50 値を集計します。 |
| [characterization-curation](skills/characterization-curation/SKILL.md) | 化合物の同一性、バッチ、NMR・IR・HRMS・HPLC の根拠資料を対応付け、出典と不足項目を整理します。 |
| [chemdraw-ole](skills/chemdraw-ole/SKILL.md) | ネイティブ形式の化学構造図を作成し、Office 内の編集可能な ChemDraw オブジェクトを確認・納品します。 |
| [scientific-figure-format](skills/scientific-figure-format/SKILL.md) | 特定の作図ソフトに依存せず、研究用図版のラベル、レイアウト、文字組み、表示の完全性を確認します。 |
| [illustrator-scientific-figure](skills/illustrator-scientific-figure/SKILL.md) | Illustrator で編集可能な研究用図版を組み立て、保存・再オープン・エクスポートを確認します。 |

## エージェントで使う

リポジトリをクローンします。

```sh
git clone https://github.com/ESRShbb/scientific-workflow-skills.git
```

`skills/` から必要なスキルのフォルダーを、自分のプロジェクトの `.agents/skills/` にコピーしてください。スクリプトと参考資料を含め、フォルダー全体を保持します。この配置に対応するツールでは自動検出できます。それ以外では、該当する `SKILL.md` をエージェントに直接読ませるか、利用するツールの仕様に合わせてスキルの配置先を設定してください。`agents/openai.yaml` は任意のツール向けメタデータです。

自動検出に対応していない場合は、プロジェクトの `AGENTS.md` に短い案内を追加できます。

```text
NMR の作業では .agents/skills/nmr-processing/SKILL.md を読み、
依頼された操作に必要な参考資料を参照する。元データの作業用コピーを使う。
```

あとは、入力ファイルの場所と希望する出力を、普段の言葉で伝えます。

> この MNOVA ファイルの 1、2 ページを PNG にして、新しい出力フォルダーに保存して。元ファイルは変更しないで。

> この PZFX ファイルから XY データを取り出して、サンプル名や濃度の単位が不明な箇所を教えて。

> この図のラベルとレイアウトを確認して、修正が必要な箇所を具体的に示して。

エージェントには、ローカルファイルの読み取りとスクリプト実行のためのツール・権限が必要です。ネイティブ形式の操作には、インストール済みアプリケーションを操作する機能も必要です。こうした機能のないモデルやチャット画面では、手順を読むだけで実際の処理を実行することはできません。

## 動作環境

- Python 補助スクリプトには Python 3.10 以降が必要です。付属の移植性テストは標準ライブラリのみを使用します。
- ネイティブ操作には、対象ソフトの別途インストールと有効なライセンスが必要です。対象は MestReNova、GraphPad Prism、ChemDraw、Microsoft Office、Adobe Illustrator です。
- 付属の起動用・COM 補助スクリプトは主に Windows 向けです。一部の手順には PowerShell や、任意の依存パッケージ `pywin32` が必要です。詳細は各スキルの参考資料を参照してください。データの所在整理、静的検査、数値集計のすべてに専用ソフトが必要なわけではありません。
- 図版書式のスキルはレビュー手法を提供するもので、ソフトウェアを実行するドライバーは含みません。

Windows で `python` が古いインタープリターを指している場合は、`py -3` を使ってください。他のシステムでは、環境に合った Python 3 のコマンドを使用します。

## パッケージを確認する

```sh
python -B scripts/validate.py
```

スキルのエントリーポイント、ローカルの Markdown リンク、Python の構文を確認した後、付属の合成データによるテストを個別のプロセスで実行します。研究用ソフトを起動するものではなく、科学的な正しさを保証するものでもありません。GitHub Actions でも Windows と Linux 上で同じ検査を行います。

別のコンピューターでの実行、FID 処理の全工程、異なるソフトウェアバージョン間での無人の新規フィッティングは未検証です。Prism では一部の結果の読み取りにバージョン間の差が見られたため、実際のモデル、入力データとの対応、設定を確認する必要があります。スクリプトのテスト合格は、研究ワークフロー全体の検証完了を意味しません。

非公開の実験データやアプリケーション本体は配布していません。テスト用データはコードで生成します。スキル本体と詳細な参考資料は現在、英語で管理しています。このファイルは日本語の利用案内です。[第三者製品に関する注記](THIRD_PARTY_NOTICES.md)と [MIT ライセンス](LICENSE)もご覧ください。
