# Validation and capability boundaries

Locally executable: source/locator/hash/selection contracts. Chemical identity, measurements and status declarations require actual review.

Run `python3 -B -m unittest discover -s /path/to/skill/scripts/tests -v` from another project directory. Windows may use `py -3.12 -B`. Tests use synthetic file/metadata fixtures, not native scientific acquisitions.

## Cases

1. Two selected sources for one sample/batch/modality without an explicit complementary group: report ambiguity.
2. Missing, unselected or unusable material remains distinct from verified evidence; do not fabricate files.
3. Real project: trace an NMR/HRMS/HPLC set through records, sample/batch and final text; reconcile one conflicting alias or adduct. Scientific case deferred.

No test on a single host proves another computer, OS, software version or license is compatible. Record the actual environment and separate static, native, visual and scientific conclusions. Local helper success must not be reported as full workflow validation.

## Revision 0.2.0 focused checks

Separate literal source values, computed ppm and proposed adduct; preserve ambiguous dates and batch gaps. Correct unclear scan digits only after original-resolution region inspection.

Treat scripts added in 0.2.0 as target-installation probes; consult their actual task logs. Package tests do not certify arbitrary native inputs or other computers.
