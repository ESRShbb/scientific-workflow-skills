# Scientific figure format

This is a methods skill with no software driver. Read [layout and review](references/layout-and-review.md); read [scientific content types](references/content-types.md) for relevant panel types.

First establish whether the task is one standalone figure, multiple independent figures or a composite; identify allowed changes, source mapping, destination dimensions and scientific content that must remain unchanged. Do not invent panel letters or composite structure from an old artboard.

Verify labels, units, category order, normalization, statistical meaning and entity nomenclature before styling. Source artwork can contain errors. Formatting must not silently choose between conflicting scientific sources or alter data to create visual symmetry.

Create a layout with shared lane/category centers, baselines, label edges and gutters. Choose typography/line weights from actual output size, reference or publication requirements. Specific font sizes and coordinate tolerances are examples/parameters, not universal acceptance criteria.

Review the latest saved/rendered result at whole-figure, panel/detail and actual intended-size views. Structural checks and visual acceptance are separate. A figure can contain all objects and still have ambiguous label correspondence or unreadable text.

For review-only requests, report localized findings without modifying files. For edits, pass concrete constraints to the available drawing tool; no particular application or companion skill is mandatory. Distinguish observed problems from unverified concerns.

Version 0.2.3 is an extracted methods candidate. [Validation cases](references/validation.md) exercise scope and scientific decisions. Static package checks do not certify visual judgment. No invented executable or empty test harness is needed for this methods-only skill.
